# Record Shelf v0.10.0 — Code & Test Audit

> **Date:** 2026-06-06 · **Commit audited:** e9b28f2 · **Method:** 26-agent Opus 4.8 review across testing/logic/quality/standards, adversarially verified (52 findings kept, 0 false positives; several down-severified).

## Executive Summary

By hobby-app standards the codebase is in good shape: the pure-logic layer (`src/lib/utils/*`, stores, the param matcher, hooks, the KV cache helper, three API endpoints) is genuinely well tested — 190 passing unit tests with a reusable SvelteKit mock pattern. **But there is no testing structure for the part of the app users actually see.** A harness exists only for `.ts` modules; **zero of 41 Svelte components are tested, and no component-rendering harness is installed** (no `@testing-library/svelte`, no `jsdom`, no `test.environment` — `vite.config.ts:6`). The coverage gate is structurally blind to it: `coverage.include` is `['src/lib/**/*.ts','src/routes/**/*.ts']` (`vite.config.ts:10`), excluding every `.svelte` file, so ~66% is measured only over already-tested code. Logic holes are mostly latent edge cases plus a few real client state bugs. Code quality is dominated by copy-paste of page chrome, charts, and CSS.

## 1) Testing structure

**Zero-coverage surface, ranked by risk:** compare loader (0%, densest server logic) **[high]**; `/api/value-history` **[med]**; `/api/widget` (public/CORS) **[med]**; wantlist loader **[med]**; both actions (`keyboardNav`, `reveal`) **[med]**; service-worker **[low]**. **All 41 components: zero tests, no harness [med].**

**Test-quality concerns:** value tests never exercise the KV/SWR path (no `platform`, cache unmocked) **[med]**; route-test `json()` mock discards headers (CORS/cache-control untestable) **[med]**; hooks test never verifies CSP/env branch **[med]**; SWR stale-serve untested **[low]**.

**E2E:** shallow smoke only; runs with no token + no API stub, so the core `/u/[username]` render path is verified by neither unit nor e2e **[med]**.

## 2) Logic holes

- **Dead SWR on `/u/[username]`** [med] — `+page.server.ts:24-31` ignores `cached.stale`/`waitUntil`; only `/api/collection` does SWR.
- **LazyImage keeps stale `loaded`/`error` on `src` change in unkeyed lists** [med] — `LazyImage.svelte:4-37`, `CollectionTimeline.svelte:51` (unkeyed `{#each}`).
- **`/api/value` ~55s for a fresh 50-item sample** [med] — serialized 1100ms loop; fragile to timeouts (not a guaranteed crash — Cloudflare bills CPU).
- `computeCollectionStats` `NaN-NaN` month bucket for invalid date [low]; non-numeric `Retry-After`→~0ms backoff [low]; value sums across currencies [low]; `RandomPicker` timers mutate state post-teardown [low]; `value-history` trusts stored shape (no `Array.isArray`) [low]; `SectionNav` last-intersecting-wins flicker [low]; `CollectingCalendar` UTC-key/local-grid off-by-one [low]; SW no offline nav fallback [low]; `CollectionQuiz` <4 options / dup-title mis-score [low]; `ValueEstimate` memoized `sampledIds` stale on items change [low]; matcher accepts separator-only usernames [info].

## Recommended order of attack

1. Install component-test harness (jsdom + @testing-library/svelte).
2. Add `.svelte` + `service-worker.ts` to `coverage.include` (re-baseline threshold).
3. Fix dead SWR on `/u/[username]`.
4. Test the compare loader.
5. Fix LazyImage stale state.
6. Bound `/api/value` work.
7. Quick logic-hardening batch (NaN date guard, Retry-After finite check, value-history Array.isArray, matcher alphanumeric, widget num_collection guard).
8. Add stubbed-Discogs e2e for core flows.
9. Standards cleanup (`./$types`, `PageServerLoad`, unify `error()`).
10. De-duplication (RecordLogo/SiteHeader/SiteFooter, global `.card`/`.spinner`, CHART_PALETTE, compare/wantlist reuse).
